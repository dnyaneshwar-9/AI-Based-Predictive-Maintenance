# AI-Based Predictive Maintenance Using Machine Learning

## 1. Project Overview

This project explores the use of machine learning to identify potential machine failures using industrial operating data. Multiple classification algorithms are compared to understand their ability to detect failure cases.

## 2. Objectives

* Analyze the AI4I 2020 Predictive Maintenance Dataset.
* Preprocess data for machine learning.
* Train and compare classification algorithms.
* Evaluate models using accuracy, precision, recall, and F1-score.
* Investigate class imbalance and classification thresholds.
* Understand the trade-off between missed failures and false alarms.

## 3. Dataset

**Dataset:** AI4I 2020 Predictive Maintenance Dataset.

The dataset contains synthetic industrial operating records and variables such as:

* Air temperature
* Process temperature
* Rotational speed
* Torque
* Tool wear
* Machine type
* Machine failure label

**Note:** The dataset is synthetic. Its results do not, by themselves, demonstrate that the model is ready for deployment in a real factory.

## 4. Algorithms

The project explores these machine learning algorithms:

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Machine (SVM)
5. K-Nearest Neighbors (KNN)

Additional experiments investigate class-imbalance handling and different prediction thresholds.

## 7. Evaluation Metrics

* **Accuracy:** Percentage of all predictions that are correct.
* **Precision:** Percentage of predicted failures that are actual failures.
* **Recall:** Percentage of actual failures detected.
* **F1-score:** A combined measure of precision and recall.
* **Confusion Matrix:** Shows correct and incorrect predictions by class.

Because machine failures are relatively rare, accuracy alone may be misleading. Recall is particularly important when missing a failure could be costly.

## 10. Limitations

* The dataset contains synthetic rather than actual factory measurements.
* Results depend on the data, preprocessing, model settings, and classification threshold.
* Identifying failure-associated records is not the same as predicting the exact time of a future breakdown.
* Real-world deployment requires additional testing using appropriate industrial data.
